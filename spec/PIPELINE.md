# Execution Pipeline

## 1. Strategy
Defines product intent and user problems.

## 2. UX Core
Defines schema, flows, and interaction rules.

## 3. Experience Design
Defines UI layouts, components, visual system.

## 4. Content
Defines templates, microcopy, AI prompts.

## 5. Engineering
Implements frontend architecture.

## 6. Growth
Improves onboarding, retention, engagement.

## 7. Validation
Tests usability and measures effectiveness.

## 8. AI Layer
Adds automation and intelligence.

## 9. Trust Layer
Ensures privacy, control, and offline capability.

---

## Trigger Rules

- Schema changes → UX Core + Engineering
- UI changes → Experience Design
- AI updates → AI Layer
